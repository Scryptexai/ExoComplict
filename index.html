Buka build mentah

Kontrol

Keyboard: WASD bergerak · tahan klik kanan untuk membidik · tahan klik kiri untuk menembak · E ganti senjata · klik EMP · Esc pause · R reset run.

Sentuh: joystick ibu jari kiri untuk bergerak · geser sisi kanan untuk membidik · tombol FIRE / WEAPON / EMP / PAUSE di kanan.

Preview ini memakai build single-thread supaya bisa dilayani python -m http.server tanpa header COOP/COEP.

Build web belum ada?

  1. Ambil artefak web-preview dari GitHub Actions (tab Actions → run terakhir → Artifacts).
  2. Ekstrak isinya ke root repo ini, sehingga muncul folder web/.
  3. Muat ulang halaman ini.

Punya Godot 4.7.2 + export templates? Bangun sendiri:

./scripts/export_web_preview.sh

Menjalankan server

python -m http.server 800 --bind 0.0.0.0

Lalu buka http://localhost:800/, atau http://<ip-perangkat>:800/ dari HP di jaringan yang sama.

Python 3.9+ sudah mengirim .wasm sebagai application/wasm, jadi tidak perlu konfigurasi tambahan.

Batas preview ini

  • Renderer wajib Compatibility (WebGL 2); bukan Forward+/Mobile renderer Android.
  • Angka FPS/frame time di sini bukan ukuran performa Android.
  • Build single-thread tidak memakai Thread; hindari menilai audio latency/paralelisme dari preview.
  • Validasi kontrol sentuh, build Android, dan profiling perangkat tetap butuh jalur ANDROID_BASELINE.md.
Preview WebAssembly untuk review UI/UX dan gameplay saja. Pipeline produksi tetap: Godot + Blender di mesin dev, lalu export Android sesuai ANDROID_BASELINE.md. Detail teknis: WEB_PREVIEW.md.
