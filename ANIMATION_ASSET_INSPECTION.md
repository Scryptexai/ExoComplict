## Implementation decision

The current gameplay controller, projectiles, target damage, and wave system remain in place. The player now instances the user-selected tier-1 GLB and maps horizontal movement speed to the supplied `idle`, `walk`, and `run` clips; no new bones or custom animation were invented. The common model is high-poly and its rights metadata was not included in Drive, so confirm licensing/redistribution rights before a public or commercial release and profile/optimize it before Android claims. The tier-2/tier-3 models and gun remain audit-only. Weapon grip, muzzle, and firing alignment remain blocked until the actual weapon is measured and tested. No world scene was changed.

## Verification boundary

- **VERIFIED:** Drive listing/metadata, file sizes, GLB JSON and buffer structure, mesh bounds/counts, skin/joint counts, animation names/durations, and embedded texture dimensions.
- **VERIFIED only as an auxiliary preview:** armored humanoid silhouettes and rifle-like gun shape. These software renders do not replace Blender/Godot inspection.
- **Static checks:** GDScript lint/format can be run locally; Godot is not installed in this sandbox, so no current import/runtime smoke result is claimed.
- **UNKNOWN:** Blender viewport pose/deformation, Godot imported node/animation names and playback, in-game orientation/scale, weapon grip/muzzle transforms, Android GPU/memory performance, and license terms beyond the user-provided Drive provenance.
